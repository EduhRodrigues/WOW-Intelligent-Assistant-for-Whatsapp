WOW! AI-Powered Restaurant Assistant for WhatsApp

## Overview

WOW! is a proof-of-concept chatbot designed to automate restaurant customer service and order management through WhatsApp.

The project integrates Dialogflow, Firebase Functions, and JavaScript to create conversational flows capable of handling customer requests, menu navigation, reservations, and order processing.

## Features

* WhatsApp chatbot integration
* Dialogflow conversational intents
* Restaurant menu navigation
* Order registration flow
* Delivery and pickup options
* Customer interaction automation
* Firebase Cloud Functions backend

## Technologies

* JavaScript
* Dialogflow
* Firebase Functions
* Firebase Admin SDK
* Firestore

## Architecture

WhatsApp User → Dialogflow → Firebase Functions → Business Logic → Order Processing

## Project Status

🚀 Prototype / Proof of Concept

This project was developed as a proof of concept and learning experience.

Core conversational flows were successfully implemented, including menu navigation, reservations, and order handling. Some advanced features, such as multi-item order calculations and production deployment, were not completed.
