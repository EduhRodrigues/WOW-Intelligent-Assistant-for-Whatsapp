WOW! AI-Powered Restaurant Assistant for WhatsApp

## Overview

WOW! is a chatbot prototype developed to automate restaurant customer service through WhatsApp.

The project integrates Dialogflow, Firebase Functions, and JavaScript to create conversational flows capable of handling customer requests, menu navigation, reservations, and order processing.

## Features

* WhatsApp chatbot integration
* Dialogflow conversational intents
* Restaurant menu navigation
* Order registration flow
* Delivery and pickup options
* Customer interaction automation
* Firebase Cloud Functions backend

## Technologies

* JavaScript
* Dialogflow
* Firebase Functions
* Firebase Admin SDK
* Firestore

## Project Status

⚠️ Prototype / Learning Project

This project was developed as a proof of concept and learning experience.

Core conversational flows were implemented successfully, but some advanced features such as complete order total calculations and production deployment were not finalized.
